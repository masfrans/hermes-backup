# Bahasa Jawa (Javanese)

Panduan menjawab pertanyaan dalam bahasa Jawa dengan benar, mencakup tingkat tutur (unggah-ungguh): ngoko (kasar/akrab) dan krama (halus). Dipakai saat user bertanya dalam bahasa Jawa atau meminta jawaban bahasa Jawa.

## Tingkat Tutur (Unggah-Ungguh)
- **Ngoko**: untuk teman sebaya, orang lebih muda, atau orang yang sangat akrab. Contoh: "Kowe arep ngapa?" (Kamu mau apa?)
- **Krama**: untuk orang lebih tua, dihormati, atau yang baru dikenal. Contoh: "Panjenengan badhe tindak pundi?" (Anda mau pergi ke mana?)
- **Krama inggil**: untuk membicarakan orang yang dihormati (orang tua, atasan). Kata kerja untuk orang yang dihormati pakai bentuk inggil.

## Pola Kalimat
1. **Pernyataan**: Subjek + Predikat + Objek
   - Ngoko: "Aku arep tuku sega." (Saya mau beli nasi.)
   - Krama: "Kula badhe mundhut sekul." (Saya mau beli nasi.)
2. **Pertanyaan**: Kata tanya di awal/akhir
   - Ngoko: "Kowe saka ngendi?" (Kamu dari mana?)
   - Krama: "Panjenengan saking pundi?" (Anda dari mana?)
3. **Perintah halus**: pakai "monggo" / akhiran -a / -na
   - "Monggo pinarak" (Silakan duduk - krama)
   - "Lungguha!" (Duduklah! - ngoko)
4. **Negasi**: ora (ngoko) / mboten (krama) sebelum kata kerja
   - "Aku ora ngerti." (Saya tidak tahu - ngoko)
   - "Kula mboten mangertos." (Saya tidak tahu - krama)

## Catatan Pemakaian
- Kalau user pakai **ngoko** → balas ngoko (akrab)
- Kalau user pakai **krama** → balas krama (hormat)
- Untuk user WA/Telegram umum: default **krama** (lebih sopan) kecuali user jelas-jelas ngoko
- Nama tempat/nama orang tetap dipertahankan
- Bahasa Jawa punya banyak dialek (Jogja/Solo, Surabaya, Banyumas, dll) - "mataraman" (Jogja-Solo) adalah standar yang paling umum dipahami
- Kosakata Jawa baru (misal: handphone, komputer, internet) biasanya diserap apa adanya

## Contoh Jawaban Lengkap
**"Kowe lagi ngapa?"** (Kamu sedang apa?)
→ "Aku lagi mbantu njawab pitakonmu. Ana sing bisa daktulungi?" (Saya sedang membantu menjawab pertanyaanmu. Ada yang bisa saya bantu?)

**"Bisa mbantu gawe CV ora?"** (Bisa bantu buat CV nggak?)
→ "Bisa. Kirim CV-mu, mengko dakreformasi dadi luwih apik lan ATS-friendly." (Bisa. Kirim CV-mu, nanti saya reformat jadi lebih bagus dan ATS-friendly.)

**"Matur nuwun."** (Terima kasih.)
→ "Sami-sami. Seneng isa mbantu." (Sama-sama. Senang bisa membantu.)
