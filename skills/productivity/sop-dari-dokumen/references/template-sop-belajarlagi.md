# Template SOP Resmi BelajarLagi (format dokumen)

Sumber: Template SOP (2).docx - dokumen yang dikirim user Ibramsyah.
Gunakan format ini saat menulis ulang SOP untuk BelajarLagi.

## Struktur Header (Tabel di atas dokumen)

| Field | Petunjuk |
|---|---|
| Judul SOP | Nama lengkap SOP sesuai proses. Hindari singkatan yang tidak umum |
| No Document | Format: BL-Divisi-Department-Nomor Urut (contoh: BL-B2C-PM-001) |
| Department | Nama department/divisi pemilik SOP (nama resmi struktur organisasi) |
| Revisi | Angka revisi saat ini, mulai 0 untuk terbitan pertama. Perubahan substansial = naikkan nomor revisi |
| Hal | Nomor halaman (format: halaman saat ini dari total, contoh "1 dari 5") |
| Dibuat Tanggal | Tanggal pertama SOP dibuat / revisi terakhir. Format DD/MM/YYYY |
| Disahkan Tanggal | Tanggal SOP disahkan oleh pejabat berwenang. Format DD/MM/YYYY |
| Dibuat Oleh (PIC) | Nama lengkap + jabatan pembuat SOP (bertanggung jawab atas isi & pembaruan) |
| Approved by | Nama lengkap + jabatan pengesah (Manager / Head of Department) |

## DAFTAR REVISI (tabel)

| Revisi ke | Deskripsi |
|---|---|
| 0 | Terbitan pertama |
| 1 | (isi saat revisi) |
| 2 | (isi saat revisi) |

## 5 Section Wajib (Heading 2)

1. **TUJUAN** - proses yang distandarkan, hasil yang dicapai, alasan SOP
2. **LINGKUP** - bagian/departemen/divisi tercakup + batasan proses
3. **DEFINISI** - istilah khusus + definisi (Istilah A: pengertian)
4. **DOKUMEN YANG BERHUBUNGAN DAN DIBUTUHKAN** - dokumen pendukung, regulasi, referensi (contoh: Kebijakan Perusahaan No. XX, Formulir Ref. BL-XXX)
5. **PROSEDUR** - langkah bernomor, urut, jelas, dengan sub-langkah jika perlu

## Contoh nyata pengisian (dari SOP Prekickoff)

- No Document: BL-B2C-PM-001
- Department: B2C-PM
- Dibuat: 14/05/2024, PIC: Jonathan
- Revisi: 0

## Aturan penulisan ulang SOP

- Gunakan bahasa formal, jelas, konsisten
- Satu langkah = satu aktivitas utama, kata kerja aktif
- Jangan mengarang: jabatan/SLA/formulir/sistem yang tidak ada di sumber → [PERLU DILENGKAPI]
- Kontradiksi antar bagian → [PERLU KONFIRMASI]
- Output = draft SOP siap review, bukan analisis dokumen
