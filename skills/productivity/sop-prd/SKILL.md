# SOP Penyusunan PRD + Template PRD

## KAPAN PAKAI
Saat diminta membuat, mengisi, atau review dokumen PRD atau SOP program BelajarLagi (free class, webinar, mini bootcamp, bootcamp).

---

## DEFINISI

- **PRD** (Program Requirements Document): Dokumen perencanaan program yang merangkum seluruh informasi teknis dan konten untuk merancang dan menjalankan program Bootcamp atau Pelatihan.
- **Bootcamp**: Program pembelajaran intensif, beberapa sesi Live Class + aktivitas belajar.
- **Cohort**: Angkatan/batch peserta. Contoh: Cohort-1, Cohort-2.
- **Live Class**: Sesi pembelajaran langsung (synchronous) terjadwal.
- **Instructor**: Pengajar/fasilitator materi program.
- **Pain Points**: Hambatan/masalah nyata target peserta.
- **Gain Points**: Manfaat/keahlian baru setelah mengikuti program.
- **Benchmarking**: Riset komparatif terhadap program serupa sebagai referensi.

---

## LANGKAH-LANGKAH SOP

### Langkah 1: Persiapan Dokumen
1. Buka template PRD terbaru dari Google Drive
2. Buat salinan dengan nama: `PRD_[Nama Program]_Cohort-[N]_[BulanTahun]`
3. Isi header: Title, Date, Instructor, Duration

### Langkah 2: Riset & Benchmarking
1. Analisis kompetitor dan tren pasar
2. Catat URL referensi yang valid di bagian Benchmarking & Riset Topics
3. Cakup: tren industri, program serupa kompetitor

### Langkah 3: Analisis Target Peserta
1. Identifikasi Target Audience: rentang usia, profesi, karakteristik
2. Definisikan Pain Points (hambatan nyata)
3. Definisikan Gain Points (manfaat konkret)
4. Rumuskan Main Issue dari Pain Points + riset

### Langkah 4: Penyusunan Objective & Silabus
1. Susun objective yang menjawab Pain Points (spesifik, terukur, relevan)
2. Rancang Talking Points/Silabus per sesi (minimal 3-4 subtopik)
3. Diskusi dengan SME/Instructor untuk validasi silabus
4. Koordinasikan dengan Instructor untuk kedalaman materi

### Langkah 5: Penyusunan Timeline
1. Isi jadwal lengkap setiap sesi (tanggal, jam, tipe sesi)
2. Pastikan sesuai dengan Kalender Program BelajarLagi 2026
3. Perhatikan: tanggal merah, Opening/Graduation, jeda antar sesi
4. Sesuaikan jeda untuk persiapan teknis dan marketing

### Catatan Timeline Ideal:

| Tipe Program | Mulai Registrasi | Akhir Registrasi | Persiapan Team |
|---|---|---|---|
| **Bootcamp** | H-60 sebelum Opening | H-9 sebelum Opening | H-30 |
| **Mini Bootcamp** | H-30 sebelum Opening | H-3 sebelum Opening | H-21 |
| **Webinar** | H-30 sebelum Opening | H-1 sebelum Opening | H-14 |
| **Free Class** | H-14 sebelum Opening | Hari H Opening | - |
